# Security

## Reporting a vulnerability

Please report security issues privately rather than opening a public issue: use GitHub's
**"Report a vulnerability"** (Security → Advisories) on this repository, or email the maintainer
listed on the GitHub profile. You'll get an acknowledgement within a few days.

## Threat model

**Reaching the panel is sensitive.** Two things make it so:

1. The panel can **launch `claude` sessions** in arbitrary directories, and Claude can execute
   code. So being able to POST to the API is, in effect, code execution as the host user.
2. The session list carries **message snippets and titles** — fragments of conversation
   content.

claude-rc is therefore designed to be reachable only by you.

### What Tailscale gives you

When exposed via `claude-rc expose` (i.e. `tailscale serve`), the panel is reachable only by
devices in **your** tailnet, authenticated by your identity provider and encrypted with
WireGuard. That's mutual authentication at the network layer — stronger than a bearer token on
an open port. There is **no public surface** (we never use `tailscale funnel`).

### What Tailscale does *not* cover (and how we handle it)

- **Other local users on the same host.** The panel binds `127.0.0.1`, which any local user can
  reach. → The API requires a **bearer token** (generated by `setup`, stored `0600`). A local
  user without the token gets `401`.
- **CSRF from your own browser.** Your phone's browser is on the tailnet. → The token is stored
  as a **`SameSite=Strict`, `HttpOnly` cookie**, so a cross-site page can't ride it. (This also
  works for the SSE stream, which can't carry custom headers.)
- **Data at rest.** Per-session enrichment files (which include a message snippet) are written
  `0600` under `~/.local/state/claude-rc`, and the panel only ever surfaces a short snippet,
  never the full transcript.

### Footguns we refuse

- `serve` **refuses to bind a non-loopback address without a token**, so you can't accidentally
  publish an unauthenticated panel to your LAN.
- `expose` only ever does tailnet `serve`. It never offers `tailscale funnel`.

## Defaults summary

| | Default |
|---|---|
| Bind | `127.0.0.1` (loopback) |
| Public internet | never (no funnel) |
| API auth | bearer token (required when configured) |
| Token transport | `SameSite=Strict; HttpOnly` cookie, or `Authorization: Bearer` / `x-crc-token` |
| Token comparison | constant-time |
| Enrichment files | `0600`, snippet only |

## Relationship to Anthropic's policy

claude-rc invokes the official `claude` binary with an official flag and uses the official hooks
API. It does **not** proxy your account, OAuth tokens, or login, and does not provide
"Claude login" to any third party. It is an unofficial tool and not affiliated with Anthropic.
